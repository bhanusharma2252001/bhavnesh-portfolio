Marketplace · Lead backend May 2025 – Aug 2025 · Loop Methods

Rebookit — subscription-based used-book marketplace

One backend serving web, mobile and admin apps. Readers buy and sell books, subscribe, join community discussions and chat with each other in real time.

Web · Mobile · Admin→Nginx→NestJS API→ MongoDB replica setElasticsearchWebSocket gateway→ELK monitoring

Challenge

Buyers and sellers needed to find books quickly and talk to each other directly. The platform had to stay online with a very small team running it.

What I built

  • Real-time buyer–seller chat over WebSockets with low-latency, two-way messaging
  • Full-text search and faceted filtering in Elasticsearch
  • MongoDB replica sets for redundancy and automatic failover
  • Centralised ELK logging that tracks API failure rates and helps debug production issues

Outcome

The platform went to production on AWS with Docker, PM2 and Nginx. Backups, monitoring and CI/CD were in place, and I mentored junior developers along the way.

An end-to-end procurement system that coordinates buyers, vendors and procurement partners on one platform.

Buyers · Vendors · Partners→Nginx→Node.js API · PM2→MongoDBStripeS3 presigned uploads
